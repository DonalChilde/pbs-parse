# Dependencies

This is a list fo the dependencies used in this project.

- typer: The cli library used for the command line linterface.
- pyparsing: A text parsing library used during the parsing of data.
- tzdata: A package containing curent timezone data.
- whenever: A libaray for working with dates and times that solves many of the issues the standard library has around working with datetimes and timezones.
- pydantic: A validation library used to support the serialization and deserialization fo the data models.
- pyyaml: Supports for data output in the YAML format.
- pfmsoft-pdf2txt: The program used to extract txt from pdf files. A cli skin over the pdfminer.six library.
- airportsdata: The dataset used to look up timezones for airports.
